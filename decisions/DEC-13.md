## 13. The coding agent standard: agents follow the same rules and are named

*Decided 30 October 2026, in standards version 2026-10-30.1.*

**Decided.** Coding agents follow the same rules as people, and the person who asks for a change is responsible for it, whoever wrote it. Every commit an agent makes ends with a `Co-Authored-By:` trailer naming the agent and model, and anything an agent posts under a person's account says who wrote it. Personal data, learner data and secrets are not pasted into AI tools.

Readers should be able to tell what a person wrote from what an agent wrote on their behalf, in the history and in public. Responsibility stays with a person because an agent cannot answer for a change later.

The alternative was a rule that the person submitting a change must understand every line. Nothing can check that rule, so it would slowly stop being followed. Independent review and tests check the change itself ([DEC-11](DEC-11.md), [DEC-12](DEC-12.md)).

**Obligations.**

- **Follow the [coding agent standard](../STANDARDS.md#coding-agent-standard)** in every repository an agent works in.
