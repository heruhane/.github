# heruhane/.github
Public information and code standards for the heruhane org.

- [`CONTRIBUTING.md`](CONTRIBUTING.md): how changes are made through pull requests, and how a heruhane repository adopts that rule.
- [`TOOLING.md`](TOOLING.md): the heruhane tooling standard, which names the tools every heruhane repository uses and how it runs them.
- [`decisions/`](decisions/): the decisions behind the standards, one file each.
- [`profile/README.md`](profile/README.md): the organisation profile shown on GitHub.
