# Security policy

This policy covers heruhane's repositories and websites. GitHub shows it on any heruhane repository that has no `SECURITY.md` of its own.

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue, discussion or pull request.

Use [private vulnerability reporting](https://github.com/heruhane/.github/security/advisories/new) on `heruhane/.github`, even if the problem is in another heruhane repository or on a heruhane website.

Tell us:

- what is affected, such as a repository or a web address;
- how to reproduce the problem;
- what someone could do by exploiting it.

Please do not access other people's data, disrupt a service, or test more than you need to show the problem.

## What to expect

heruhane is a small organisation. We read every report, and we will work with you on a fix. We do not yet promise a response time, and we do not offer a bug bounty. If you would like to be credited when the problem is fixed, say so in your report.
